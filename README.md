# Validador de Cédula - Algoritmo Módulo 10

## Descripción
Servicio web para validar cédulas dominicanas usando el algoritmo del Módulo 10.

## Funcionalidades
- Ingreso de cédula (11 dígitos)
- Validación con Módulo 10
- Mensaje: Válida o Inválida

## Uso de IA
Se utilizó Inteligencia Artificial como apoyo para estructurar el código y explicar el algoritmo.
